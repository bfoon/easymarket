  • Shipments are numbered sequentially (#1, #2, #3, etc.)
  • Order status will be updated to "Shipped" on first shipment

Quick Guide
How It Works:
  1. Select Order: Choose from orders with warehouse-shipped items
  2. Review Items: Preview shows items to be included automatically
  3. Fill Details: Enter weight, dimensions, and schedule
  4. Assign Resources: Optionally assign driver and vehicle
  5. Create: Shipment is created with sequential number
Important Notes:
  • Only items marked as "shipped to warehouse" are included
  • Multiple shipments can be created for same order
  • First shipment updates order status to "Shipped"
  • Items are automatically linked to this shipment
